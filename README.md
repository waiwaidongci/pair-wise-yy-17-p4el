# 钟乳石洞穴微环境巡测 · 仪器校准与巡测准入闭环

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在 `data/db.json`，后续可以继续增量迭代。

## 闭环规则

- **巡测准入**：每次巡测必须绑定当次设备与有效校准记录（校准与设备匹配、结果合格、在有效期内、读数在设备量程内）。校准过期、设备/校准停用、结果不合格或量程不符时，记录只 **留档待复测**，不进入异常统计。
- **设备领用**：同一设备未归还不能再次分配；换班交接时连同当前校准状态一并交接留痕。
- **校准更正**：校准结果更正后，依赖它的未复核巡测自动失效留档、统计重算；已复查记录不受影响。
- **重测恢复**：留档记录可改绑校准后重测，重测合格才恢复（回到留档前状态），否则继续留档。
- **幂等提交**：重复提交沿用首次记录（提交键 + 内容天然键双重判重）。
- **一致性**：列表、统计与刷新后状态同源（服务端持久化，操作后整体重取）。

## 分层结构

规则判断、存储和界面分开实现：

```
src/rules.js   规则层：准入评估、校准有效性、量程核对、分配/交接、更正级联、重测、幂等（纯函数，不碰 IO）
src/store.js   存储层：db.json 读写（原子写入）、id/历史戳
server.js      HTTP 层：路由装配，调用规则层与存储层
project.config.js  界面配置：集合、视图、统计、动作（含守卫/参数/可见条件）
public/        界面层：配置驱动渲染，业务判定全部交给服务端
test/e2e.test.js   闭环端到端测试（需先 npm start，再 npm test）
```

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/surveys` | 登记巡测（准入评估 + 幂等） |
| POST | `/api/surveys/:id/retest` | 重测（合格才恢复） |
| POST | `/api/devices/:id/assign` `/return` `/handover` | 设备分配 / 归还 / 换班交接 |
| POST | `/api/calibrations/:id/correct` | 校准更正（级联失效未复核巡测） |
| POST | `/api/action/:actionId/:id` | 配置驱动动作（标记异常、完成复查等，含守卫） |
| GET | `/api/db` | 全量数据（含派生的校准有效性标签） |
