# 钟乳石洞穴微环境巡测

仪器校准与巡测准入闭环：围绕洞穴、分区、样点和巡测路线记录微环境数据，每次巡测必须绑定当次设备与有效校准记录，发现异常后生成复查闭环。

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在 `data/db.json`，后续可以继续增量迭代。

## 测试

```bash
npm test
```

端到端冒烟测试会用临时数据文件启动独立服务进程，覆盖准入判定、重复提交、设备分配、换班交接、校准更正级联与重测恢复。

## 闭环规则

- **巡测准入**：每次巡测必须绑定当次设备与校准记录。设备停用、缺少校准、校准不合格、校准过期（巡测日期超出有效期）或量程不符（温度超出设备量程）时，巡测只留档为「待复测」，不进入异常统计，也不能标记异常或完成复查。
- **设备分配**：同一设备未归还不能再次分配；领用中的设备不能停用；换班交接时自动生成当前校准状态快照（结果、有效期、是否过期）随设备一起交接。
- **校准更正**：校准结果或有效期被更正后，依赖它的未复核巡测立即失效（留档待复测）并重算统计；已复核的巡测不受影响。
- **重测恢复**：待复测巡测只有通过重测（重新绑定设备与有效校准、复测指标）才能恢复为有效巡测。
- **重复提交**：同一提交（幂等键或同样点/设备/日期/人员的自然键）只保留首次记录，重复提交返回原记录。
- **状态一致**：列表、看板与统计均由服务端数据实时推导，任何操作后刷新页面状态一致。

## 代码结构（规则 / 存储 / 界面分离）

```
server/rules.js     规则判断层：准入判定、分配约束、校准快照、更正级联（纯函数，无 I/O）
server/store.js     存储层：db.json 原子读写与读-改-写事务
server/handlers.js  业务动作层：分配/归还/换班/校准更正/重测，组合规则与存储
server.js           HTTP 接线层：路由、通用 CRUD 与动作引擎
project.config.js   界面配置：集合、视图、统计、动作声明
public/             界面层：配置驱动的渲染、动作弹窗、级联下拉
scripts/smoke.js    端到端冒烟测试
```
